# D.C. Code § 28:1-205. Reasonable time; seasonableness.

- (a) Whether a time for taking an action required by this subtitle is reasonable depends on the nature, purpose, and circumstances of the action.
- (b) An action is taken seasonably if it is taken at or within the time agreed or, if no time is agreed, at or within a reasonable time.
